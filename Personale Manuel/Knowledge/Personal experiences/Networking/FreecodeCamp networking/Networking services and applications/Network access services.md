# **Network Interface controller (NIC)**
>anche chiamato network interface card

Il NIC è l' hardware che permette al dispositivo di connettersi alla rete.

>Lavora su layer del modello OSI:
- **layer 2:** fornisce il mezzo funzioanale di comunicazione di rete determinando che protocollo verrà usato (Ethernet, point-to-point). Fornisce anche il MAC address al nodo
- **layer 1:** determina come il traffico di dati venga convertito da singoli bit a segnali elettrici che attraverseranno la rete.

# **Remote Authentication Dial In User Service (RADIUS)**
>Un servizio di accesso remoto usato per autenticare utenti remoti e garantirgli l'accesso a risorse di rete autorizzate

>E' un protocollo AAA (Autentication , Authorization, Accounting) usato per assicurare che **solo utenti autenticati stanno usando risorse di rete che sono autorizzati ad usare**

>[!IMPORTANT] Solamente la password del richiedente è criptata
# **Terminal Access Controller Access-Control Systems Plus (TACACS+)
>Un servizio di accesso remoto usato per autenticare dispositivi remoti e garantirgli l'accesso al risorse di rete autorizzate

>Protocollo AAA usato per assicurare che **solo dispositivi di rete remoti autorizzati stiano utilizzando risorse che sono autorizzati ad usare**

>[!IMPORTANT] Tutte le trasmission tra dispositivi sono criptate.

# Altri servizi e applicazioni

## **Remote Access Services (RAS)**
>Roadmap descrizione di hardware e software necessari per stabile una connessione remota.

>Un client che richiede una connessione remota ad un server che lascia o non accedere

## **Web Services**
>Creare i mezzi per la comunicazione tra pacchetti software. Solitamente ottenuto tramite la traduzione della comunicazione in un xml (Extensible Markup Language)

## **Unified voice servers**
>Una descrizione della combinazione di software e hardware richiesti per integrare canali per la comunicazione orale in una rete.
