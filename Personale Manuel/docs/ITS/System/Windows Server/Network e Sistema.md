#Windows 

>- Verificare se dal BIOS il sistema è bootable con USB o DVD
>- Eventualmente modificare le opzioni di boot per adattare al supporto di installazione scelto
>- Inserire il supporto di installazione ed avviare il sistema
>- Controllare che il sistema parta dal supporto scelto (se non parte ricontrollare le opzioni di boot)
>- Iniziare l'installazione seguendo le istruzioni fornite dal programma di installazione

# **RDP (Remote Desktop Access) Porta 3389
>Uno standard per potersi collegare ai sistemi Windows in modo rapido, veloce e nativo.
>E' possibile usarlo solamente se attivato sul sistema di destinazione, **di default è disabilitato**
>Utilizza le stesse credenziali che si usano per accedere al sistema con la console
>E' presente come applicativo anche su altri sistemi non Windows
>E' possibile avviarlo tramite riga di comando del sottosistema DOS dei sistemi Windows

>Per usarlo come Admin Console:
>- Programmi -> Accessori -> Connessione Desktop remoto
>oppure
>- Esecuzione da riga di comando con elenco switches
>  %windir%\system32\mtsc.exe /?
>oppure tool alternativi
>- mRemoteNG
