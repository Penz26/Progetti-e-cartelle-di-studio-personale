## Opzione: Aggiungi ruoli e funzionalità
>Tramite il menù che si aprirà potremo installare servizi che si possono attivare.
>Alcuni di questi:
>- DNS server, ATTENZIONE: SOLAMENTE UNA
>- samba,
>- WINS Server, (serve per identificare il nostro dispositivo con un solo IP in base al MAC address) **prenotazione di un indirizzo IP**
>- ecc...

- Selezionare i servizi da installare e installarli
>[!NOTE] **(2° regola del sistemista)** 
>Consigliato fare backup prima e dopo l'installazione di servizi se qualcosa va storto 

### Configurazione DNS
>- Nome,
>- Descrizione,
>- IP INIZIO,
>- IP FINE,
>- Subnet,
>- Indirizzo Ip del Router, (senza router il traffico non va all'esterno)
